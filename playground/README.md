# playground

The reference consumer of the `kestrel-web` layer, used for local development (`pnpm dev` from the
repo root runs this app). See `../docs/consuming-kestrel-web.md` for what each file here
(`kestrel.config.ts`, `kestrel.modules.ts`, `pipelines/`, `shared/model.ts`, `app/blocks/`) does and
how to reproduce it in your own app.
